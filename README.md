# 🌍 The Problem

Finding a reliable technician during an emergency is frustrating and inefficient.

Residents often rely on:

- WhatsApp groups
- Personal contacts
- Outdated directories
- Manual searching

This process suffers from:

❌ No transparency  
❌ No real-time tracking  
❌ No accountability  
❌ Language barriers  
❌ No visual diagnosis  
❌ Poor provider matching

---

# 💡 Our Solution

AetherFlow AI is a multi-agent concierge platform that autonomously orchestrates the entire service journey.

Users can simply:

- Type a request
- Speak naturally
- Upload a photo

The platform automatically:

✅ Understands the problem  
✅ Extracts location  
✅ Finds nearby professionals  
✅ Ranks providers  
✅ Creates bookings  
✅ Tracks technician progress  
✅ Generates traces and explanations

---

# 🤖 Why Agents?

Traditional applications require users to manually:

- Search
- Compare
- Coordinate
- Follow up

AetherFlow delegates these tasks to specialized AI agents.

Each agent has a single responsibility:

```text
Intent Agent
↓
Location Agent
↓
Provider Agent
↓
Ranking Agent
↓
Booking Agent
↓
Assignment Agent
↓
Tracking & Trace Agent
```

This enables:

- Autonomous execution
- Better decision making
- Lower user friction
- Explainable workflows

# ⚙️ Local Setup

## Clone Repository

```bash
git clone <repo-url>
cd AetherFlow
```

## Install Dependencies

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## TypeScript Verification

```bash
npx tsc --noEmit
```
